| exempt\_pipeline\_roles | IAM role names whose security-group changes are not emailed, for automation that rewrites<br/>security groups on every run and would otherwise drown the changes a person needs to see. The default exempts nobody. | `list(string)` | `[]` | no |

Set it true only for an account with<br/>no trail; tools/check\_cloudtrail.sh tells the two cases apart. | `bool` | `false` | no |
